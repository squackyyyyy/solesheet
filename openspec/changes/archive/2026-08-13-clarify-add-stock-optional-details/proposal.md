## Why

The Add Stock preview promises an essentials-first workflow but does not show where less common inventory details can be entered, while its current reference to photos and supplier data conflicts with the scoped initial product. A compact collapsed disclosure can make the workflow feel complete without weakening the primary Add pair action or depicting unsupported functionality.

## What Changes

- Add a collapsed **Optional details** disclosure row to the Add Stock phone composition between the target-price field and the primary Add pair action.
- Identify the supported hidden fields as **Date acquired**, **Status**, and **Notes**, and explain that sellers can add or edit them later.
- Keep the disclosure collapsed in the static desktop and mobile product photographs; controls pictured inside the phone remain illustrative and non-operable on the website.
- Remove the existing “Photos, notes, and supplier can wait” copy so the preview no longer implies item-photo or supplier management is part of the initial product.
- Update the Add Stock content registry, equivalent image description, responsive generated assets, and focused validation coverage to reflect the clarified composition.

None.

- `product-mockup-showcase`: Clarify the essentials-first Add Stock requirement with a visible collapsed optional-details disclosure that names only supported inventory fields and preserves the prominence of the Add pair action.
